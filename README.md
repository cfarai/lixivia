# Thrash Crossover Band Portfolio Website

Build a modern, responsive portfolio website for my thrash crossover band. The website should have a dark, aggressive, professional aesthetic inspired by 80s thrash metal, hardcore punk, underground zines, and live concert photography. The design should feel authentic rather than generic.

## General Requirements

* Responsive on desktop, tablet, and mobile.

* Fast loading.

* Smooth scrolling.

* Clean, organized code.

* Modern animations that are subtle and don't distract.

* Accessibility and SEO-friendly structure.

* Use React + TypeScript + Tailwind CSS if applicable.

I will upload:

* The band's logo.

* Band photos.

* Additional images for the gallery and sections.

Generate the color palette automatically from the uploaded logo and use those colors consistently throughout the website.

# Style Guide

Overall mood:

* Dark.

* Heavy.

* Powerful.

* Minimal but atmospheric.

Visual inspiration:

* Thrash Metal

* Hardcore Punk

* Underground flyers

* Vintage concert posters

* Album artwork

* High contrast

* Subtle distressed textures

* Modern UI mixed with old-school metal aesthetics

Avoid clichés like skulls everywhere or excessive flames. The design should feel authentic, premium, and focused on the band's identity.

Use the uploaded logo to determine the primary color palette, typography, and overall visual identity.

Leave all text content as editable placeholders so I can replace it later.
